# Flappy Bird

This project is a recreation of the classic **Flappy Bird** game, developed in **Unity** as part of an assignment for the **Algorithms and Programming II** course.  
The goal was to apply fundamental programming concepts and game logic in a practical environment using a professional game engine.

---

## Project Objective

Recreate the core mechanics of Flappy Bird while **adding different and original mechanics**, focusing on:

- Character control with gravity-based physics  
- Procedural generation of obstacles  
- Collision detection  
- Simple scoring system
